# Суть

Веб-приложение для извлечения масок артикулов из сертификатов поставщиков и генерации полного списка артикулов, соответствующих этим маскам.

## О проекте

Поставщики автозапчастей указывают в сертификатах артикулы в виде масок, например `4VB****`. Такие записи описывают множество возможных артикулов, но не содержат их полного перечня.

Программа читает документ поставщика, извлекает из него маски и генерирует все возможные комбинации артикулов. Результат сохраняется в CSV-файлы, которые упаковываются в ZIP-архив для скачивания через веб-интерфейс.

Решение реализовано в соответствии с уточнённым техническим заданием: на вход подаётся сертификат с масками, на выходе пользователь получает полный список артикулов, удовлетворяющих требованиям масок.

> **Примечание.** Если задача заключается не в получении полного перечня, а в проверке уже существующих каталожных артикулов, генерация всех комбинаций не требуется. В таком случае эффективнее преобразовать маски в регулярные выражения и проверять артикулы непосредственно по ним. Однако в рамках данного проекта реализована именно генерация полного списка.

## Как работает

Работа с сертификатом состоит из нескольких этапов:

1. **Загрузка документа.** Пользователь загружает сертификат поставщика через веб-интерфейс.

2. **Чтение документа.** Программа извлекает текст из файлов форматов `.txt`, `.md`, `.csv`, `.tsv`, `.docx`, `.xlsx` и `.pdf`. Для PDF поддерживаются документы с текстовым слоем. Обработка сканированных документов не реализована.

3. **Извлечение масок.** Пользователь выбирает один из двух режимов:
   - **Регулярное выражение.** Маски извлекаются по шаблону, основанному на правилах из образца HI-LEX. Символ `*` обозначает одну позицию подстановки. Корректность этого подхода на сертификатах других производителей не гарантируется. В режиме регулярных выражений автоматическое определение производителя и товарной группы не реализовано. Эти данные пользователь указывает вручную.
   - **ИИ-агент.** Извлечённый текст передаётся агенту на базе DeepSeek. Он определяет маски, производителя и товарную группу с учётом контекста документа.



4. **Подтверждение данных.** Найденные маски и сопутствующая информация отображаются в интерфейсе. Перед генерацией пользователь может проверить и скорректировать результат.

5. **Генерация артикулов.** Для каждой маски формируются все возможные комбинации. Генерация выполняется потоково, без загрузки полного набора артикулов в оперативную память.

6. **Получение результата.** Сформированные CSV-файлы упаковываются в ZIP-архив. Пользователь получает возможность скачать его через веб-интерфейс.

## Особенности генерации

В качестве образца правил использован документ HI-LEX. Он содержит 38 масок с трёхсимвольным префиксом и четырьмя позициями подстановки.

Используемый алфавит:
- цифры `0–9`;
- заглавные латинские буквы `A–Z`.

Всего 36 допустимых символов. Одна маска с четырьмя позициями подстановки даёт:

`36⁴ = 1 679 616` комбинаций.

Для всех 38 масок получается **63 825 408 артикулов**.

Ориентировочный размер CSV-файла для такого набора — около 511–575 МБ, в зависимости от формата записи и подсчёта размера. Такой объём не предназначен для ручного просмотра в Excel: лимит одного листа составляет 1 048 576 строк. Результат рассчитан прежде всего на последующую загрузку и обработку в других системах.

Для каждой комбинации производителя и товарной группы формируется отдельный CSV-файл с колонкой `article`. Имя файла имеет вид:

`производитель__товарная группа.csv`

Сформированные файлы объединяются в ZIP-архив.

**Важно:** правила HI-LEX используются как пример. Реальные ограничения на допустимые символы и комбинации у других производителей неизвестны. Программа не вводит дополнительные ограничения, не подтверждённые документацией.

## Структура проекта

Проект разделён на два основных пакета:

### `core`

Содержит основную логику обработки данных и не зависит от веб-интерфейса.

- `document_reader.py` — чтение документов и извлечение текста.
- `mask_extraction/re_extractor.py` — извлечение масок регулярными выражениями.
- `mask_extraction/ai_extractor.py` — извлечение данных с помощью DeepSeek.
- `mask_extraction/mask_extraction_prompt.md` — системный промпт ИИ-агента.
- `article_generator.py` — генерация артикулов, запись CSV и упаковка результатов в ZIP.
- `doc.md` — подробное описание пакета


### `web_app`

Содержит веб-сервер и пользовательский интерфейс.

- `main.py` — создание приложения FastAPI и подключение маршрутизаторов.
- `routers/` — обработчики страниц, извлечения данных и генерации.
- `jobs/` — управление задачами и выполнение длительных операций в отдельных процессах.
- `templates/` — HTML-шаблоны интерфейса.
- `static/` — CSS-стили и JavaScript-код клиентской части.
- `doc.md` — подробное описание пакета

Веб-приложение связывает пользовательский интерфейс с компонентами `core`, управляет последовательностью обработки документа и предоставляет пользователю результаты.

## Запуск

Проект тестировался на Python 3.12 и Linux.

Вариант 1. Запуск из виртуального окружения:
- Создать в корне проекта файл .env c переменными окружения. Задать API-ключ в переменной DEEPSEEK_API_KEY.
- Установить зависимости из requirements.txt
Запуск приложения из корневой директории проекта

```bash
python3 run.py
```
Вариант 2. Поднять и запустить docker контейнер:
```bash
docker build -t articles_generator .
```
При запуске контейнера обязательно указываем параметрами переменные окружения
```bash
docker run -d \
    --name articles_generator \
    -e HOST=0.0.0.0 \
    -e PORT=10111 \
    -e DEEPSEEK_API_KEY="api_ключ" \
    -p 10111:10111 \
    -v "$(pwd)/tmp:/app/tmp" \
    articles_generator
```

В браузере обратиться по адресу http://localhost:10111(по умолчанию)

## Ограничения
- Извлечение масок регулярными выражениями ориентировано на правила образца HI-LEX. Для надёжной работы с другими производителями могут потребоваться дополнительные шаблоны.
- Чтение сканированных PDF не поддерживается. Для этого потребуется отдельный OCR-модуль, например на основе Tesseract.
- ИИ-извлечение зависит от доступности DeepSeek API, корректности модели и ограничений API.
- Производитель и товарная группа в режиме регулярных выражений заполняются вручную: пример реального сертификата не предоставлен, поэтому шаблоны извлечения этих данных составить не на чем
- Генерация больших наборов артикулов может занимать продолжительное время, поэтому тяжёлые операции выносятся из основного процесса веб-приложения.
